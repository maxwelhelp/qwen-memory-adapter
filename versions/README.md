# Версии кода памяти (хронология)

Все итерации «как я делал память» — от ранних попыток до рабочей версии.
Оригиналы также лежат в `test_titans/` (рабочая папка экспериментов).

| Файл | Что делает | Результат |
|---|---|---|
| `v1_train_memory.py` | Ранняя механика: delta-rule по головам внимания, дистилляция на y_attn (выход внимания). Обучаемые η, проекция выхода | Линейная delta-память не аппроксимирует внимание (cosine ~0) — заброшено |
| `v2_train_mlp_memory.py` | **Первая MLP-память** (Titans-стиль, 896→3584→896) + дистилляция y_attn, запись батч-градиентами с create_graph | MLP СХЛОПНУЛСЯ к нулю: 2 шага записи на весь контекст, нет η/γ, нет учителя на уровне дистилляции |
| `v3_smoke_memory.py` | Smoke готового NeuralMemory из titans-pytorch (без изменений) | Референс: как выглядит рабочая механика Titans из коробки |
| `v4_smoke_memory_slots.py` | Синтетический тест СЛОТОВ: запись пар (k→v) чанками, η/γ, изоляция слотов, γ-стирание, перезапись фактов, персистентность save/load, L_fast/L_slow | Механика жива: запись −44% ошибки (линейный слот), γ-стирание работает, изоляция работает |
| `v5_train_memory_distill.py` | **РАБОЧАЯ версия** (текущая, в корне репозитория — её копия): alignment (M(h)≈h) → η-голова → дистилляция сдвига логпробов кандидатов. Линейные слоты (34/40) или MLP-слоты (24/40) — переключается конфигом (SlotMLP vs Linear) | Межсессионный тест: 85% линейная / 60% MLP+η / шанс 12% |

Хронология провалов и фиксов — в `../docs/REPORT_MEMORY_MLP.md` (раздел 4) и
`../docs/RESULTS.md`.
