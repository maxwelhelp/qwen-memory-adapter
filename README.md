# Обучаемая MLP-память для Qwen (qwen-memory-adapter)

Персистентная память для замороженной Qwen2.5-0.5B-Instruct: **память живёт в весах
маленькой MLP-сети**, а не в KV-кэше. Qwen читает контекст в «сессии 1» — память
записывает его в свои веса градиентными шагами. В «сессии 2» (новый промпт, кэш
Qwen выброшен) память подмешивает знание обратно — Qwen отвечает так, как будто
контекст ещё перед ней.

```
Сессия 1:  контекст (секрет в мусоре) → память пишет (веса MLP = память)
Сессия 2:  только вопрос → Qwen без контекста + подмешивание из памяти → правильный ответ
```

## Результаты (кратко, подробно — docs/RESULTS.md)

Межсессионный тест (40 примеров: 4 типа «Пароль/Код/Пин-код/Секрет: X» в мусоре):

| Версия памяти | Правильных ответов |
|---|---|
| Без памяти (шанс) | 5/40 (12%) |
| **Линейные слоты** | **34/40 (85%)** |
| MLP-слоты | 23/40 (57%) |
| MLP-слоты + η-голова («что писать») | 24/40 (60%) |
| С контекстом (эталон, dense) | 40/40 |

Память работает: без контекста модель отвечает правильно в 85% (линейная версия)
против 12% шанса.

## Как это работает

1. **Память = слоты**: 32 слота × MLP (896→H→896, GELU, без bias, xavier) —
   веса слотов и есть память.
2. **Запись** (необучаемая механика, Titans-правило): для каждого токена контекста
   градиентный шаг самовосстановления `θ ← θ(1−γ) − η·∇||M(h)−h||²`, нормированный,
   чанками (CHUNK=16), ITERS итераций. **η-голова** (`σ(W_eta(h))`) решает «как сильно
   писать токен» (учитель: секрет=1, мусор=0.1) — novelty гейтит запись.
3. **Чтение** (обучаемое): веса слотов выбираются маршрутизацией `softmax(q·W_route)`;
   mix = g·W_out(Σ w_i·(M_i(q; запись) − M_i(q; θ₀))) — 6 чисел = сдвиг логпробов
   кандидатов; финальные логиты = логиты без контекста + mix.
4. **Обучение** (Qwen заморожена):
   - Фаза 1 — **alignment**: слоты учатся воспроизводить скрытые состояния Qwen
     (M(h)≈h) — память «говорит на языке Qwen»;
   - Фаза 1.5 — **η-голова** (что писать);
   - Фаза 2 — **дистилляция**: слоты заморожены, обучаются W_route, W_out, g
     (loss = CE по кандидатам + MSE сдвига логпробов).

## Структура проекта

### Скрипты (в корне)

| Файл | Что делает |
|---|---|
| `gen_yattn.py` | Генерирует датасет дистилляции: 400 примеров (4 типа задач), Δ = выход с контекстом − без, mask_secret для η-головы → `dataset_yattn.pt` |
| `train_memory_distill.py` | Обучение памяти: alignment → η-голова → дистилляция → `memory_distill.pt` |
| `eval_cross_session.py` | **Межсессионный тест** (главная метрика): сессия 1 пишет, сессия 2 отвечает без контекста |
| `smoke_memory_slots.py` | Синтетический тест механики записи (слоты, η/γ, чанки, изоляция, персистентность) |
| `gen_knowledge_dataset.py` | Шаг 1: датасет know/not-know с эмпирическими лейблами (срез знаний) → `dataset_knowledge.pt` |
| `train_knowledge_clf.py` | Шаг 1: классификатор know/not-know (92%) — онлайн-сигнал новизны → `clf_knowledge.pt` |
| `eval_memory.py` | Абляция: baseline / пустая память / с записью |
| `eval_delta_check.py` | Контроль: содержит ли Δ (эффект контекста) правильную информацию |

## Запуск

Зависимости: Python 3.12, torch 2.6.0+cu124 (Tesla P40, sm_6.1), transformers 4.57.6.

```bash
# 1. датасет дистилляции (400 примеров, ~10 мин на P40)
python gen_yattn.py

# 2. обучение памяти (alignment + η + дистилляция, ~1-2 ч)
python train_memory_distill.py

# 3. межсессионный тест — главная метрика
python eval_cross_session.py
```

Опционально (шаг 1 — сигнал новизны для η/θ-гейта):
```bash
python gen_knowledge_dataset.py   # датасет know/not-know (эмпирические лейблы)
python train_knowledge_clf.py     # классификатор (92%)
```

Данные/веса (`*.pt`) в git не хранятся — генерируются скриптами (см. .gitignore).

## Железо / контекст

- Модель: Qwen/Qwen2.5-0.5B-Instruct (hidden 896, 26 слоёв, eager attention — P40
  не поддерживает flash-attn2).
- Всё обучение — только память; Qwen заморожена (никакого end-to-end).
- Память между сессиями: `memory_distill.pt` сохраняется на диск и загружается
  в новой сессии — кэш Qwen выброшен, память помнит.

## Известные ограничения

- MLP-версия уступает линейной в текущей схеме (разность откликов у нелинейных
  слотов слабее); план её усиления — в `docs/REPORT_MEMORY_MLP.md` (3.3: полный
  bilevel TTT-стиля).
- 0.5B не умеет применять «правила» даже с контекстом — правило-задача отложена
  до 1.5B.
