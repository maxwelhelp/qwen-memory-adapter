# Архитектура: обучаемая MLP-память для Qwen

Сводный документ. Детали плана — `memory_layer_v2.md`, разбор отклонений —
`REPORT_MEMORY_MLP.md`, результаты — `RESULTS.md`.

## 1. Идея

Рядом с **замороженной** Qwen2.5-0.5B-Instruct живёт маленькая сеть-память.
Её **веса — это и есть память**: контекст записывается в них градиентными
шагами (Titans-стиль), при вопросе память читается и подмешивается в ответ.
Ключевой сценарий — **персистентность между сессиями**: кэш Qwen выбрасывается,
веса памяти сохраняются — память помнит то, что Qwen забыла.

## 2. Компоненты

```
                    Qwen (ЗАМОРОЖЕНА, не трогается)
                              │
        hidden-состояния контекста (вход последнего слоя, 896)
                              │
        ┌─────────────────────▼──────────────────────┐
        │  ПАМЯТЬ                                      │
        │                                              │
        │  N_SLOTS=32 слота × SlotMLP                   │
        │    Linear(896→H)→GELU→Linear(H→896),          │
        │    без bias, xavier_uniform                   │
        │    (H конфигурируем: 256/512/896)             │
        │                                              │
        │  ЗАПИСЬ (необучаемая механика, на инференсе): │
        │    маршрут: s = argmax(h · route_keys)        │
        │    шаг:  θ_s ← θ_s(1−γ) − η_t·∇||M(h)−h||²    │
        │    нормированный, чанками (CHUNK=16), ITERS   │
        │    η_t = σ(W_eta(h_t)) — «как сильно писать»  │
        │    (учитель: секрет=1, мусор=0.1)             │
        │                                              │
        │  ЧТЕНИЕ (обучаемое извлечение):               │
        │    веса слотов: w = softmax(q · W_route)      │
        │    mix = g·W_out(Σ_i w_i·(M_i(q;запись)−      │
        │                              M_i(q;θ₀)))      │
        │    mix — 6 чисел = сдвиг логпробов кандидатов │
        └─────────────────────┬────────────────────────┘
                              │ mix
                              ▼
        final_logits[кандидаты] = logits_noctx[кандидаты] + mix
```

## 3. Фазы обучения (Qwen заморожена, учится только память)

| Фаза | Что учится | Лосс | Цель |
|---|---|---|---|
| 1. Alignment | слоты θ₀ | `\|\|M(h)−h\|\|²` на скрытых состояниях Qwen | память «говорит на языке Qwen» (пространство выровнено) |
| 1.5. η-голова | W_eta | BCE(σ(W_eta(h)), mask_secret) | «что писать»: секрет сильно, мусор слабо |
| 2. Дистилляция | W_route, W_out, g (слоты ЗАМОРОЖЕНЫ) | CE(кандидаты) + 0.5·MSE(mix, target6) | память отдаёт то, что нужно для правильного ответа |

target6 = логпробы кандидатов с контекстом − без контекста (целевой сдвиг).

## 4. Инференс (персистентность между сессиями)

```
Сессия 1:  контекст → write_work (градиентные шаги по клонам слотов)
           веса памяти (memory_distill.pt) сохраняются на диск
           кэш Qwen выброшен

Сессия 2:  только вопрос → forward Qwen без контекста
           q = hidden последней позиции (вход последнего слоя)
           mix = g·W_out(Σ w_i·(M_i(q;запись) − M_i(q;θ₀)))
           pred = argmax(логпробы кандидатов без контекста + mix)
```

## 5. Ключевые решения (почему так)

1. **Запись необучаемая, чтение обучаемое.** Bilevel-градиенты через запись
   не доходят (клоны весов обрывают граф, mix≈0) — 7 прогонов шанса. Разделение:
   запись = механика хранения (нормированные шаги), чтение = обучаемое извлечение.
   Это разделение труда «запись — организация пространства, чтение — извлечение».
2. **Alignment обязателен.** Пространство слотов (случайное) не связано с
   пространством Qwen — дистилляция учила и семантику, и механику одновременно.
   Alignment (M(h)≈h) выравнивает пространства.
3. **Выход в логпроб-пространство кандидатов** (6 чисел) вместо подмешивания
   вектора в hidden: Δ выхода ~150 при ||h||~15, norm() давил и сигнал, и
   градиенты в ~150 раз — векторная дистилляция не достигала нужной точности.
   Сдвиг логпробов — прямая метрика.
4. **MLP-слоты без residual-обёртки.** Residual (MLP(x)+x, как в Titans) сводит
   запись к нулю (||MLP(h)||²→0) и обнуляет разность откликов — mix≈0.
   (В Titans residual нужен — там память это слой модели; у нас mix = разность.)
5. **Нормированные шаги записи** (ĝ = g/||g||): веса не раздуваются (взрывы
   были при ETA=0.5 на длинных контекстах).

## 6. Метрики

- Межсессионный тест (главная): 40 примеров, 4 типа задач.
  Линейные слоты 34/40 (85%) | MLP+η 24/40 (60%) | шанс 5/40 (12%).
- val_acc дистилляции: линейные 0.88 | MLP 0.70 | MLP+η 0.60.
- Классификатор know/not-know (шаг 1, сигнал новизны): 92%.

## 7. Открытые направления (REPORT_MEMORY_MLP.md)

- 3.3: полный bilevel TTT-стиля (без detach, граф через все шаги, обучаемый lr)
  — возврат к «память постоянно обучается» из исходного плана.
- L_fast/L_slow (titans_qwen2.md): двухуровневая память, порог = novelty.
- Persistent tokens-якоря.
- Правила-задача на 1.5B (0.5B не умеет применять правила даже с контекстом).
