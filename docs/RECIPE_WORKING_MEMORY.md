# 🎯 РАБОЧИЙ РЕЦЕПТ: обучаемая память для Qwen (Linear Associative Slots)

## 1. Рецепт (6 компонентов, все обязательны)

### 1. Выравнивание пространства (дистилляция эмбеддингов в MLP)
Память учится `M(h) ≈ h` на скрытых состояниях Qwen (вход последнего слоя, 896):
```
cos(M(x), x) = 0.98 на невиданных векторах | rel_err 0.17
```
Пространства ОДНО — память «говорит на языке Qwen». Без этого запись/чтение не связаны
с моделью. Проверено отдельным тестом (exp2c): случайный MLP cos=0.03, после дистилляции 0.98.

### 2. Удивление (surprise) — ЧТО писать (Titans-механизм)
Удивление токена = насколько он аномален для ВЫРОВНЕННОЙ памяти:
```
surprise_t = ‖M_θ₀(h_t) − h_t‖²
```
Различает секрет/мусор: **AUC = 0.89**, секрет удивляет в 2.86× сильнее (exp2f) —
без учителя, работает на реальных данных на инференсе. (В Titans: surprise = per-sample
градиент внутреннего лосса |M(k)−v|², neural_memory.py:400-410.)

### 3. η-гейт записи
Писать сильно только удивляющее:
```
η_t = 0.1 + 0.9·(surprise_t / max_surprise)     # или σ(W_eta(h_t)) с учителем mask_secret
если η_t < ETA_MIN_SKIP: токен НЕ пишется вовсе   # (мусор не тратит ёмкость)
```
Работают оба варианта η (маска-учитель и внутреннее удивление). Для реальных данных —
удивление (без разметки).

### 4. Ассоциативная запись delta-rule (НЕ самовосстановление!)
Память запоминает ПАРЫ «ключ → значение», а не «вход → вход»:
```
k = GELU(W_k(h_t)),  v = GELU(W_v(h_{t+1}))     # соседние токены: «маркер» → «секрет»
W_s ← W_s(1−γ) − η·∇‖W_s·k − v‖²                # delta-rule, шаг нормированный
```
Соседние пары (k_t → v_{t+1}) кодируют авторегрессию в весах: «Пароль:» → секрет.
Пары строятся из контекста — применимы на инференсе без вопроса.

### 5. ЛИНЕЙНЫЕ слоты (критично! без нелинейности)
Слот = одна матрица `W_s (896×896)`, чтение `M(q) = W_s·q`.
**Почему линейные:** нелинейный слот (MLP с GELU) НЕ является ассоциативной памятью —
для вопроса q ≠ записанного ключа k отклик M(q) произволен. Линейный слот с delta-rule:
```
W += η(v−Wk)kᵀ  →  M(q) = Wq + η(v−Wk)(k·q)     # извлечение по похожести АВТОМАТИЧЕСКИ
```
Это объясняет все провалы MLP-слотов (24/40 максимум) и успех линейных (34/40 → теперь 36/40).

### 6. Retrieval-чтение + инъекция в логпробы
```
w = softmax(q·W_route)                          # какие слоты релевантны вопросу
out = Σ_i w_i · W_i · q                          # взвешенный отклик (извлечение)
mix = g · W_out(out)                             # 6 чисел = сдвиг логпробов кандидатов
final_logits[кандидаты] = logits_noctx + mix
```
Чтение попадает в слот секрета по похожести вопроса (вопрос семантически близок маркеру
в выровненном пространстве). 6-числовой выход — рабочая схема проекта (открытый словарь —
следующий шаг, векторная инъекция oracle-проверена: acc6=1.00 при идеальной инъекции).

## 3. Ключевые уроки (что НЕ работает — не повторять)

1. **Самовосстановление ‖M(h)−h‖ как запись** — слоты кодируют «похожесть на вход»,
   cos(read_diff, target_in) = 0.014 (шум): значения (v) не попадают в запись вообще.
2. **Нелинейные слоты в retrieval-схеме** — M(q) произволен для q≠k; работают только
   как классификатор по шумному отклику (24/40).
3. **Равномерная запись без η-гейта** — мусор (~170 токенов) забивает слоты, секрет тонет
   (exp2d: acc6 шанс, g выключает память).
4. **Одна память без слотов** — «каша»: отклик усредняется по всему контексту (exp2a/2b).
5. **Обучаемая запись (bilevel) сама по себе не помогает** — градиенты доходят (exp1c),
   но без правильной структуры (линейные слоты + ассоциация + гейт) кодировать нечему.
6. **Гипотезы «пространство не выровнено» и «маршрутизация виновата» — ОТВЕРГНУТЫ**
   (cos 0.98; exp1g: 1 слот — тот же шанс).
