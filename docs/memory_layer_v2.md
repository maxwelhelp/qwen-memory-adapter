# Отдельный слой MLP-памяти (постоянно учится на контексте, подмешивает в hidden)

Статус: архитектура продумана, 2026-08-03. ОТДЕЛЬНЫЙ ЭКСПЕРИМЕНТ.

## 0. Рамка (что НЕ входит — жёстко)

- НЕ кэш, НЕ скоринг, НЕ эвикция, НЕ база, НЕ переполнение контекста.
- Внимание Qwen не трогается. Qwen заморожена. End-to-end — нет.
- Сравнение только «с памятью» vs «без памяти» на ОДНОМ И ТОМ ЖЕ полном контексте.
- Где память применять (кэш/база/сессии/длинный контекст) — РЕШЕНИЕ ПОСЛЕ результата.

## 1. Идея словами

Рядом с замороженной Qwen живёт маленькая сеть — память. Её веса — это и есть записанный
контекст. При чтении каждого токена память «проверяет себя»: умеет ли она ответить на этот
токен. Ошиблась — запоминает (сильно, если ошибка большая = удивление). Угадала — не трогает.
При вопросе память выдаёт ответ по похожести (вопрос похож на запомненный ключ → выдаётся
соответствующее значение), и её ответ подмешивается в скрытое состояние через проекцию и гейт.

Qwen участвует двумя ролями: (1) её скрытые состояния — «язык понятий» памяти;
(2) её выход внимания (y_attn) — учитель: память тренируется отвечать «как Qwen».

## 2. Архитектура

```
                    ┌─────────────────────────────────────────────┐
                    │              Qwen (ЗАМОРОЖЕНА)              │
                    │  контекст → hidden states → внимание → y_attn│
                    └──────────────┬──────────────────────────────┘
                                   │ h_t (скрытые состояния токенов)
                                   ▼
        ┌──────────────────────────────────────────────────────────┐
        │  ПАМЯТЬ: MemoryMLP M_θ (896→3584→896), веса = контекст   │
        │                                                          │
        │  ЗАПИСЬ (на каждом токене контекста):                    │
        │    k_t = W_k(h_t)      — ключ (условие)                  │
        │    v_t = W_v(h_t)      — значение (ответ)                │
        │    η_t = σ(W_η(h_t))·η_max  — как сильно учиться         │
        │    γ_t = σ(W_γ(h_t))        — сколько забыть             │
        │    S_t = ∇_θ ||M(k_t) − v_t||²  — удивление (ошибка)     │
        │    θ ← θ·(1−γ_t) − η_t·S_t    — шаг обучения памяти      │
        │                                                          │
        │  ЧТЕНИЕ (по запросу q):                                  │
        │    mem_out = M_θ(q)                                    │
        └──────────────────────────────┬───────────────────────────┘
                                       │ mem_out
                                       ▼
        h_final = h_final + g · W_out(mem_out)   — подмешивание (проекция + гейт)
        logits = lm_head(norm(h_final))          — дальше сеть как обычно
```

## 3. Словами: что, куда, зачем

| Компонент | Роль | Обучается? |
|---|---|---|
| W_k, W_v | превращают токен в (ключ, значение) — «язык понятий» | да |
| η-голова W_η | решает, как сильно учиться на токене | да |
| γ-голова W_γ | решает, сколько забыть (обучаемое забывание) | да |
| MemoryMLP M_θ | сами веса-память (контекст в сжатом виде) | да, + на инференсе (запись) |
| W_out, g | подмешивание: что и насколько добавить в hidden | да |
| Qwen | источник hidden (язык) + учитель y_attn (эталон) | НЕТ |

## 4. Обучение (только память, Qwen заморожена)

Учитель: y_attn — выход внимания Qwen для запроса (уже собран в dataset_attn.pt).

Для каждого примера:
1. Прогон контекста: память записывает (шаги обучения на токенах, детерминированные).
2. Чтение M(q) по запросу.
3. Подмешивание: h = h + g·W_out(M(q)).
4. Loss: ||выход с памятью − y_attn||² (память учится «отдавать то, что внимание хочет»).
5. Backprop ЧЕРЕЗ чтение И запись (create_graph) → учим W_k, W_v, W_η, W_γ, θ₀, W_out, g.

Дополнительный учитель для записи: сама запись учится на ||M(k)−v||² (внутренняя цель —
правильно отвечать на ключи контекста). Внешняя цель (дистилляция) связывает память с Qwen.

## 4b. Сигнал новизны из Qwen (что запоминать — «как надо»)

Qwen знает факт либо из своих 26 слоёв, либо из контекста. Мера — разница логпробов:
```
Δlogprob(токен) = logprob(токен | с контекстом) − logprob(токен | без контекста)
```
- Δ большая → знание ТОЛЬКО из контекста (новое для Qwen) → высокий η (запомнить сильно);
- Δ ≈ 0 → Qwen знала и без контекста (в слоях) → слабая запись (не тратим ёмкость);
- энтропия прогноза Qwen — дополнительный маркер новизны/неуверенности.

Δlogprob используется как УЧИТЕЛЬ для η-головы (вместо/в дополнение к самопроверке памяти).
Оба сигнала бесплатны — считаются в обычном forward.

## 4c. Главный сценарий: персистентная память МЕЖДУ сессиями

```
Сессия 1: Qwen читает статью (новые знания — только в контексте/кэше)
          ↓ запись с весами новизны (Δlogprob)
          память сохраняет знание в своих весах
          ↓ сессия закончилась
          кэш Qwen выброшен — Qwen ЗАБЫЛА статью
          веса памяти сохранены на диск — память ПОМНИТ
Сессия 2: Qwen читает вопрос
          память подмешивает знание статьи в hidden
          Qwen отвечает, как будто читала статью
```

Три фильтра «не всё, а как надо»:
1. Новизна для Qwen (Δlogprob) — неизвестное детально, известное не тратим;
2. Важность (головы: внимание/удивление/аннотация) — что пригодится для ответов;
3. Ёмкость ограничена + decay (γ) — старое/неважное вытесняется.

## 5. Прошлый провал и что чиним

train_mlp_memory.py схлопнулся к нулю. Причины и фиксы:
1. Запись 2 шагами на весь контекст → ЧАНКИ: 16–32 токена, шаг на каждый чанк (как Titans).
2. Нет η/γ → добавляем η-голову (сила записи) и γ-голову (забывание).
3. Нет учителя для записи на уровне дистилляции → учитель y_attn (уже есть в датасете).
4. Градиенты в механику не доходили → create_graph через шаги записи (bilevel, как TTT).

## 6. Порядок эксперимента

1. Механика памяти (чанки, η, γ, surprise) — проверить на синтетике: записал → прочитал
   (как smoke_memory.py, но с η/γ).
2. Обучение на dataset_attn.pt (дистилляция y_attn) — сравнить: память-адаптер против
   «без памяти» на правилах-задаче и dormant (помнит ли спящий пароль).
3. Сравнение с скорингом (80% vs 20%): память / скоринг / оба.
4. Если память работает — связка: скоринг (кэш) + память (сжатие выгруженного) + база.
